The goal is to write a kernel once, for one element, and get both the SIMD loop and the
scalar loop for the leftover elements.

```python
def kernel0[T](x: T, y: T, param0: i32) -> T:
    return x + param0 * y

def main() -> None:
    # allocate ptr_x, ptr_y, ptr_out
    vectorize[kernel0, f64, 4](ptr_x, ptr_y, 42, ptr_out, length)
```

`vectorize[kernel0, f64, 4]` is a function that loops over the data 4 elements at a time,
calling `kernel0` on `SIMD[f64, 4]` values, then finishes one element at a time, calling
`kernel0` on `f64` values. The pointer arguments are loaded as vectors, and the others
(here `42`) are passed unchanged.

It needs [advanced metaprogramming](node:advanced-metaprog): the number of arguments of the
kernel is only known when `vectorize` is specialized, so the code that loads each argument
has to be generated by unrolling over this number and by spreading tuples into calls.
The name `vectorize` and the signature above are proposals.
